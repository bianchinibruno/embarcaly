# Arquivo — o caminho B2B2C

Em 05/09/2026 o plano tinha dois caminhos. **Você escolheu o A (B2C)** — vender
para o viajante — porque é a dor que você mesmo sentiu.

O caminho B (vender para o agente de viagens independente por R$79/mês) está
preservado aqui inteiro, sem edição. Ele não foi descartado por ser ruim: prova
mais rápido dentro de 16 semanas e precisa de 60 conversas em vez de 830
ativações por mês. Perdeu por não ser a sua dor.

**Quando reabrir este arquivo:**

- Se o **G0 reprovar** — os viajantes já souberem dos próprios direitos e não
  lembrarem de perrengue caro
- Se o **G3 encerrar por aquisição** — produto bom, máquina de conteúdo parada.
  O caminho B tem o mesmo produto com um funil catorze vezes menor
- Se aparecer um agente de viagens querendo pagar. Acontece, e é sinal

Nada aqui está morto. Só está esperando.
